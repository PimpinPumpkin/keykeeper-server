# Security

PassBundle is a password manager, so security reports get our full attention.

## Reporting a vulnerability

Report it privately through GitHub: on this repository's **Security** tab, choose **Report a vulnerability**. Please don't open a public issue.

Include what you found, how to reproduce it, and what an attacker could do with it. We'll reply as soon as we can and keep you updated until it's fixed.

## Please

- Give us reasonable time to fix an issue before you disclose it.
- Only test against accounts and servers you own, or have explicit permission to test.
- Don't access, change, or delete other people's data, and don't degrade the service for others.

## In scope

This server and its API, in the current code on the `keykeeper` branch. For the apps (web vault, browser extension, desktop, CLI), report to [passbundle-clients](https://github.com/PimpinPumpkin/passbundle-clients).
